**Дополнительные указания координатора к артефактам:**
- в конституции — явное исключение «исходящий интернет разрешён только к API провайдеров для импорта расхода, за флагом, выключаемым»;

**Проверенные факты для раунда 3:**
- [Факт] Anthropic Usage and Cost API: `GET /v1/organizations/usage_report/messages` и `GET /v1/organizations/cost_report`. Нужен Admin API key. Стоимость отдаётся в USD с шагом в сутки, группировка по workspace и description (модель); разбивка по API-ключу есть только в usage. Данные появляются обычно в течение ≈ 5 минут. Подписки Claude.ai не охватываются ([источник](https://platform.claude.com/docs/en/build-with-claude/usage-cost-api)).
- [Факт] У OpenAI есть Usage API и Costs API организации с ключом администратора ([анонс](https://community.openai.com/t/introducing-the-usage-api-track-api-usage-and-costs-programmatically/1043058), [cookbook](https://developers.openai.com/cookbook/examples/completions_usage_api)). Охватывают ли они подписки ChatGPT/Codex — [Вывод: вероятно, нет], не проверено.
